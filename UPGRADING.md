# Upgrading

Upgrade guides (if any) are noted here between major versions.

## From v0 to v1

- The command to start Metronome has been renamed from `schedule:metronome` to `metronome:start`
- The `--tick-rate` option has been replace with the `metronome.tick_rate` config value and `METRONOME_TICK_RATE` env var
